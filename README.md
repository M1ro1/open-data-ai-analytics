Тема: Аналіз ринку транспортних засобів в Україні.


Мета: Створення інструментарію для обробки та аналізу даних МВС щодо реєстрації транспортних засобів.


Джерело даних: https://data.gov.ua/dataset/06779371-308f-42d7-895e-5a39833375f0/resource/3f13166f-090b-499e-8e23-e9851c5a5f67


## Використані технології
* **Python 3.12**
* **Pandas** (обробка даних)
* **SQLite + SQLAlchemy** (база даних)
* **Streamlit** (веб-інтерфейс)
* **Docker & Docker Compose** (контейнеризація)

## Інструкція із запуску (Локально)

Переконайтеся, що на вашому комп'ютері встановлено та запущено [Docker Desktop](https://www.docker.com/products/docker-desktop/).

**Крок 1.** Клонуйте репозиторій та перейдіть у папку проєкту:
```bash
git clone <посилання_на_твій_репозиторій>
cd open-data-ai-analytics

**Крок 2.** Запустіть усі сервіси однією командою:
docker compose up --build
```
